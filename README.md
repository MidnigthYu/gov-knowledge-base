# gov-knowledge-base 政务知识库 RAG 系统
面向政务领域的智能问答系统，基于 RAG 架构实现文档解析、向量检索与大模型问答，从零搭建工业级 Python 后端工程。

## 技术栈
- Python 3.10+、requests、python-dotenv、chardet
- 大模型：智谱 AI GLM、DeepSeek
- 测试：unittest / pytest
- 工程化：虚拟环境、统一日志、环境变量管理

## 目录结构
```
├── config/    # 全局配置与环境变量
├── common/    # 公共组件（日志等）
├── client/    # 大模型等第三方客户端
├── utils/     # 文本清洗、文件处理工具
├── tests/     # 单元测试
├── main.py    # 项目入口
└── requirements.txt
```

## 核心实现
1. **多模型客户端**：原生 requests 封装两款大模型单轮调用，按厂商拆分文件，职责隔离，预留统一抽象扩展空间
2. **政务文本清洗**：多编码自动识别+多级兜底，支持空行、冗余空格、特殊字符过滤，递归批量处理且单文件异常不中断整体任务
3. **工程化基础**：密钥与代码分离、全局统一日志、分层目录架构，符合工业级项目开发规范

## 技术亮点
- 分层模块化设计，低耦合易扩展
- 多模型可插拔架构，兼顾初期开发效率与长期架构灵活性
- 全场景异常兜底，保障批量任务鲁棒性
- 核心函数配套单元测试，支持回归验证

## 项目进度
✅ 已完成：工程骨架搭建、双大模型客户端、文本清洗工具、基础单元测试


## 快速开始
1. 创建并激活虚拟环境，执行 `pip install -r requirements.txt` 安装依赖
2. 复制 `.env.example` 为 `.env`，填入对应 API 密钥
3. 运行项目：`python main.py`
4. 执行单元测试：`python -m unittest tests.test_text_cleaner`
